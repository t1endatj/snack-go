# snack-go

SnackGo là ứng dụng Android đặt đồ ăn vặt và đồ uống, xây dựng bằng Java, XML và SQLite.

## chức năng chính

- đăng ký, đăng nhập và quản lý phiên người dùng
- xem, tìm kiếm và lọc sản phẩm
- xem chi tiết sản phẩm và thư viện hình ảnh
- thêm sản phẩm vào giỏ hàng và áp dụng mã giảm giá
- đặt hàng, theo dõi lịch sử và trạng thái đơn hàng
- quản lý sản phẩm dành cho tài khoản quản trị viên

## chạy dự án

Mở thư mục dự án bằng Android Studio, đồng bộ Gradle và chạy module `app` trên máy ảo hoặc thiết bị Android.
